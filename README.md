# 👟 Nike Air Jordan — Página de Produto

Recriação de uma página de detalhes de produto da **Nike**, desenvolvida com **HTML, CSS e JavaScript**.

O projeto apresenta o **Nike Air Jordan 1 Mid Masculino**, com uma interface inspirada na loja oficial da Nike e funcionalidades interativas para visualizar diferentes imagens e variações do produto.

## 🔗 Demo

Acesse o projeto online:

**https://miharaxd.github.io/nike-air-jordan-detalhes/**
